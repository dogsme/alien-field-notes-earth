## The entry

One original line of plain text: a review of planet Earth left by an alien tourist, at most 200 characters. A judge model compares the lines two at a time, weighing the alien's one-line review of Earth first, then funniness, originality, whether it reads like a real review, and how tight the writing is.

## How it works

`main.py` (Python 3.13, standard library only) writes the review to `/output/entry.txt`:

```sh
python3 main.py
```

The output is a single line of UTF-8 text, 146 characters, no trailing newline.
